# Changelog

## 0.2.0 - 2026-09-11

- Added container-first execution with Docker and Apptainer profiles.
- Consolidated software definitions into a single environment manifest.
- Added a dedicated BBMap read-repair process.
- Separated DAS Tool integration from MAG extraction.
- Added generalized samplesheet validation and module-level workflow structure.
- Reused one read-to-assembly mapping across MetaBAT2, MaxBin2, and CONCOCT.
- Namespaced extracted MAG filenames to prevent cross-sample collisions.
- Added publication, database, and container documentation.
- Retained the original project scripts under `legacy/` for provenance.
